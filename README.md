### ⚙️ Systems & Architecture

- **[RISC-V Assembler](https://github.com/AVTG-1/RISCV_Assembler)** — translates 32-bit RISC-V assembly into machine code across all six instruction formats, with address calculation and data-segment directives.
- **[RISC-V Pipeline Simulator](https://github.com/AVTG-1/RISCV-Pipeline-Execution)** — five-stage pipelined execution with data forwarding, hazard detection, stalling, flushing and dynamic branch prediction.
- **[RV32I Functional Simulator](https://github.com/AVTG-1/RV32I_-Subset-_Simulator)** — cycle-accurate 32-bit simulator with per-stage logging and register/memory state dumps.
- **[ChampSim V-Way Cache](https://github.com/AVTG-1/Champsim-V-Way-Cache-Implementation)** — custom V-Way cache built into the ChampSim microarchitecture simulator.
- **[CUCU Compiler](https://github.com/AVTG-1/Custom-CUCU-Compiler-for-Toy-C-Language)** — compiler for a toy C-like language, written in C.
- **[xv6 Memory Management](https://github.com/AVTG-1/xv6_Project)** — custom memory-management functionality added to the xv6 teaching kernel.
- **[RedisDB](https://github.com/AVTG-1/Basic-Redis-Server-Implementation)** — Redis clone in Go with RESP protocol parsing and append-only-file persistence.
- **[Pixel-Squeeze](https://github.com/AVTG-1/Pixel-Squeeze)** — lossless BMP compression comparing a custom Huffman implementation against Deflate.
